# 凭证钱包与按挑战出示

本版在既有手机审批之上增加可查看的凭证校验，以及业务服务返回挑战后再出示凭证的流程。Oracle 和本机临时服务均使用同一实现。

## 手机如何查看

刷新原手机页面，保留浏览器站点数据，无需重新配对。

- **我的 Agent → 重新校验凭证**：显示关系签名、见证签名、摘要关联、有效期和在线关系状态。
- **审批记录 → 查看审批记录 → 凭证钱包与逐项校验 → 重新校验凭证**：增加请求与文件完整性、授权签名、范围和有效期、执行回执及历史执行时间检查。
- 展开 **已验签的凭证内容** 查看可读声明；展开 **按挑战出示的校验记录** 查看流水号、操作摘要、校验项及签名服务确认的记录。

“签名通过”和“当前已过期”可以同时成立。旧授权不再可用于新执行，但既有回执仍可证明历史投递。检查结果附检查时间；点击重新校验刷新在线状态，结果本身不授予执行权限。

## PC 钱包

```bash
mya wallet
mya inspect
mya inspect --request REQUEST_ID
```

库存命令只列元数据。inspect 在本机真实验签，查询带服务签名的在线状态，并输出可读凭证声明；不输出私钥或紧凑 JWS 授权串。

### 一步完成出示后执行

先按原流程提交审批并持续等待手机决定。获得批准后：

```bash
mya execute --request REQUEST_ID --presentation
mya receipt --request REQUEST_ID
```

该路径先向业务 API 获取挑战，再向指定验证入口出示凭证，核对验证回执，最后执行原来冻结的报告。原有不带 `--presentation` 的附带凭证执行方式仍可用，两条路径共用授权校验。

### 拆开查看验证方的指示

```bash
mya challenge --request REQUEST_ID --out challenge.json
mya present --request REQUEST_ID --challenge challenge.json
mya execute --request REQUEST_ID --presentation
```

challenge 文件是服务器签名的指示，包含流水号、nonce、接收验证方、提交地址、请求与操作摘要。present 只出示并验证，不产生报告投递。后续执行只接收绑定当前 Agent 的服务端流水记录，不接受 Agent 自报的“通过”。文件已存在时 challenge 命令不覆盖。

如果用户还未批准、要求修改或授权已经过期，钱包不能自行签发用户授权。改动内容需要新申请；新的挑战通常只需要新的持钥证明。批准最长 120 秒，请及时出示并执行；响应丢失时先查执行回执，不重复申请或假定成功。

## 实际边界

- Agent 钱包保管 Agent 密钥与收到的凭证；用户授权私钥留在手机。用户管理人通过手机签发授权，Agent 不持有用户签名权限。
- 出示包含关系凭证、见证、用户授权及可选自动审批委托，用 HTTPS 明文传送给已验证的服务。签名证明完整性，不提供声明保密或阻止复制；一次性 nonce、Agent 持钥证明、验证方和操作摘要约束其使用。
- 本版仅支持初始化时信任的 MYA origin，以及该 origin 的 `/v1/wallet/present`。签名指示不能新增受信服务或任意指定外站地址；HTTP 重定向拒绝。独立第三方验证方的注册、企业凭证发行与跨域信任目录尚未实现。
- 校验结果不会代替资源授权检查。资源在执行事务内再次检查期限、撤销、取消、规则状态、额度和幂等性。
- 这是自定义 JSON/JWS profile，不宣称已实现标准 DID、W3C VC 或 OpenID4VP 互操作。生物识别、分析建议继续是明确标注的模拟。
- SQLite 新增 `kv` 的 presentation 记录类型，没有破坏性表迁移。签名服务持久化出示校验事实；已执行回执增加可选 transaction_id、verification_id。
- 当前凭证持有人是本机 Agent 进程。若 Agent 能完全控制相同操作系统账号，仍可能访问本机钱包文件；独立钱包进程、硬件保护与强隔离是后续工作。

## 验证

协议测试覆盖：分步出示、服务重启、执行与历史过期显示、凭证/nonce/验证方/动作篡改、错误持钥者、并发重放、外站指示拒绝、校验后撤销/取消/暂停、过期证明与授权。

浏览器测试使用隔离的合成身份和手机视口，并调用实际 CLI。远程验收需同时设置 `MYA_TEST_ORIGIN` 与从可信渠道获得的 `MYA_TEST_WITNESS`；测试会撤销自己创建的关系，不操作现有用户关系。
