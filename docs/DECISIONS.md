# 实现决定

日期：2026-09-15。PLAN.md 是用户确认的设计基线；本文件记录首版工程取舍。

1. **纯 ESM JavaScript，Node 24，浏览器共用协议代码**。目前未引入 TypeScript 构建和大型框架；关键边界采用运行时校验与测试。前端用 esbuild 打包。未来可逐步加类型，不改变协议。
2. **HTTPS 加密消息轮询代替 WebSocket**。3 秒前台轮询，SQLite 密文 outbox，双方持钥认证、逐消息签名、JWE、去重/确认仍保留。简化 Oracle 代理与断线恢复，后续可增加 WS。
3. **Node 内置 SQLite**。无需原生 addon 编译，固定 Node 24 环境；内置模块在部分版本有实验性提示，应在生产选型时重新评估。
4. **三种手机入口**：二维码 URL、网页本地 jsQR 解码、8 位十六进制配对码。配对码只定位邀请；短码另为 40 位摘要 Crockford Base32。配对码未采用原方案建议的 Base32，但有效期/双端确认不变。
5. **真实 Web Crypto，模拟用户认证**。人工 Grant 标记 human_confirmed_demo / simulated，自动委托也保留模拟来源；服务默认拒绝，只有 ACCEPT_DEMO_ASSURANCE=true 接受。
6. **凭证为 Demo profile JSON/JWS**，不是声称符合全部 W3C VC 互通要求。DID 未做，使用 JWK 指纹。见证只验证签名、持钥和配对材料一致。
7. **固定演示公司规则**；任意自由文本不能自动批准。自动模板只有日期、里程碑、状态和完成度等有限字段。用户决定是否批准一次；规则激活是另一动作。
8. **政策修改用暂停旧规则＋新建规则**。没有原位编辑已签委托，也没有企业级策略分发。用户可在手机选择 1–3 次、1–1440 分钟；记录单独签署的委托。
9. **浏览器需要 Web Locks** 以序列化多标签操作；不支持时明确报错，未实现原方案 IndexedDB 租约锁回退。浏览器数据加密存储，但没有硬件不可导出保证。
10. **未接入现有 AWiki 原生工程**。空仓库从零实现最小 Web 闭环，不把未检出的历史模块当已复用。
11. **尚未实现历史自动清理、加密密钥恢复、生产级撤销治理、全局队列容量治理**。当前保留 Review 历史，提供主动导出；私钥保持本端。消息与挑战有 TTL 清理和每绑定配额。
12. **用户申请方与见证/资源服务同 Oracle 部署的信任限制** 已在界面/规格解释。本项目不提供完整运行时远程证明或阻止服务器改页面的能力。
