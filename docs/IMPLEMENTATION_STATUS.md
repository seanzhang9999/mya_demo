# 实现与验证状态

更新：2026-09-15。当前为 **Web 开发预览版**，不是已经上线的手机产品。

## 已实现

- 空仓库初始化、完整产品规格和开发/部署/交接文档。
- Node24 + 内置 SQLite 服务；随机生成并持久化见证/资源密钥。
- PC CLI 安装实例、邀请二维码、本地用户确认页面、手机扫码/配对码入口。
- 双端短码、用户关系签名、Agent 持钥证明、独立见证签名。
- 浏览器非导出 CryptoKey + IndexedDB；审批记录应用层加密；Web Locks 串行操作。
- JWS/JWE 的真实签名、加密、认证消息轮询与本地历史。
- 手机规则检查/明确模拟的辅助建议、要求修改、拒绝、模拟指纹确认后真实签名。
- 冻结报告、精确授权对象校验、委托范围、额度、取消、暂停和撤销检查。
- SQLite 原子投递与幂等、资源签名回执；不发送真实邮件。
- 本地 Review、复盘标记、单独启用有限规则、自动批准、站内状态与提醒。
- Codex Skill 及安装器、CLI 示例、服务部署模板。

## 本次实际验证

环境：Linux x86_64，Node v24.19.0；Playwright 1.62.1，Chromium 153.0.8010.0，390×844 手机视口。

| 验证 | 结果 |
|---|---|
| `npm run build` | 通过，手机静态目录构建 |
| `npm test` | 9 个测试通过，0 失败 |
| `npm run test:browser`（指定现有 Chromium） | 通过，真实浏览器交互 |
| Skill quick_validate | 通过 |
| 真实 CLI 子进程 | init、pair、本地确认页面、request、status、execute、doctor 通过 |
| 手机视口布局 | 无横向溢出；审批、规则截图已检查 |

协议/集成测试覆盖：重复 JSON 键、签名篡改、真实 JWE、配对、修改再申请、人工审批与回执、无授权请求、修改内容或收件人、并发重放单次副作用、规则启用/自动/例外/暂停、执行额度、取消撤销、未绑定密钥、模拟凭证默认拒绝、服务重启保持状态、过期授权与过期消息。

浏览器测试覆盖：手机页面加入配对→核对短码→人工确认→要求修改→新版本批准→真实投递回执→规则启用→页面刷新恢复→第二次自动→换接收方转人工→暂停→历史查询；额外使用真实 CLI 进程及 PC 本地确认页完成一次闭环。

浏览器官方下载地址在本执行环境超时，测试使用本地可运行的 Chromium。该运行环境依赖未加入项目运行时；正常开发者可按 README 安装 Playwright Chromium。截图环境补充了中文字体，应用本身使用设备系统字体。

测试发现并修复了一个毫秒级有效期问题：分别读取创建/截止时间，偶尔会超过严格最大期限 1 毫秒；已统一从同一时间戳生成有效窗口。
